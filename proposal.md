# Final-Project-Proposal

## Description
My proposal is a racing game where the player just has to finish a certain amount of laps. Here someone will have to stay in the track while dealing with fast speeds.

## Features
First feature is going to be a green screen with a track in the middle of it surrounded by red and white barriers. This will be made by using a screen resoulution
Second Feature is going to be a player model which is going to be a little car this will be used by bringing an image into the game.
Third Feature will be a win or lose feature where the player has to finish within a certain time limit or else the game will close and i will do this by adding a death function

# Challenges
A skill that they will need to learn is going to be knowing how to steer when the game is on
Another skill is going to be knowing your keys upside down where one key might go another way

## Outcomes
My hope is that the level plays out nicely and doesnt run into any problems and that the player is able to beat the challenges

If they cant complete the game then i hope they can at least grasp how it works
